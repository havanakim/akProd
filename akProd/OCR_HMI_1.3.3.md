# HMI OCR 1.3.3

- CP_Colored 등록 화면에서 사출·보압 / 계량·배압을 선택한다.
- 녹색 단계 헤더가 있는 상단 표만 자동 추출한다. 하단 퍼지, 사출대, 현재값, 경보, 시간 설정은 대상에서 제외한다.
- 흘림방지1 배압, 보압3·2 속도, 보압 위치는 구조적으로 없는 칸으로 비활성화한다. 인쇄된 0은 빈 칸으로 취급하지 않는다.
- 인식은 화면 처리와 분리하고, 전체 사진을 반복 분석하는 대신 열 단위로 처리한 후 남은 칸을 추가 분석한다.
- 흑백 LCD의 0 보정은 두 가지 약한 원본 정리 결과의 확인을 요구한다. 실제 8을 지우지 않도록 보호한다.
- 컬러 글꼴은 정상 OCR 0을 8·9로 되돌리지 않으며 실제 8을 0으로 강제 변경하지 않는다. 불확실한 0·8·9에는 입력 확인 표시를 제공한다.

## 검증과 한계

- 단위 검사 52개 통과, 디버그 앱 빌드 성공.
- 실기기 흑백 보압 사진 5장, HP 25칸 통과. 기존 배압 사진 회귀 검사 통과.
- 컬러 계량 사진의 측정 시간: 첫 사진 8.294초, 이후 4.637 / 5.346 / 5.584 / 5.100초. 기기와 사진에 따라 달라진다.
- 컬러 계량 및 사출 사진 전체 정답 검사는 통과하지 못했다. 균열·주사선 때문에 남는 숫자 오인식과 누락이 있으며, 완전 자동 추출이 검증된 버전으로 취급하면 안 된다.
- 최종 컬러 숫자 보호 규칙은 단위 검사로 검증했으며, 마지막 변경 후 전체 사진 재검사는 수행하지 않았다.
- 실기기 검사는 데이터베이스에 등록하지 않았다.
